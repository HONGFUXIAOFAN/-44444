## 五、标准化操作流程（5阶段）

### 阶段一：原料准备

| 步骤 | 操作 | 参数 |
|:---:|------|------|
| 1 | 选肉验收 | 色泽鲜红、脂肪乳白、无异味、触感微润 |
| 2 | 剔除筋膜 | 小刀平推去除表面粗筋膜和银膜 |
| 3 | 清洗 | 流水快速冲洗→厨房纸立即吸干（**禁止浸泡**） |
| 4 | 称量调料 | 干料/湿料/辅料分三容器备好，小苏打单独放 |

| ✅ 正确 | ❌ 错误 |
|--------|--------|
| 流水快冲→马上擦干 | 泡水里10分钟→肉吸水膨胀→烤出淡而无味 |

---

### 阶段二：切配加工

| 步骤 | 操作 | 参数 |
|:---:|------|------|
| 1 | 确认纹理 | 观察肌纤维走向 |
| 2 | 逆纹切 | 刀刃⊥纤维方向90°，切2.0cm骰子块 |
| 3 | 大小检查 | 偏差>0.3cm挑出重切 |
| 4 | 肥肉切丁 | 牛板油切1.5cm小丁 |
| 5 | 腿肉处理 | 刀背轻拍2-3下，物理断筋 |
| 6 | 肋条处理 | 切2.5cm大块，剔除硬筋膜 |

| ✅ 正确 | ❌ 错误 |
|--------|--------|
| 逆纹切（刀⊥纤维90°）→ 一咬就断 | 顺纹切 → 嚼不烂 |
| 统一2.0cm，误差<0.3cm | 大的3cm小的1cm → 受热不均 |

---

### 阶段三：腌制（核心）

| 步骤 | 操作 | 参数 | 时间 |
|:---:|------|------|:--:|
| 1 | 干料预拌 | 盐+糖+味精+鸡精+白胡椒粉+十三香+孜然+小苏打混匀 | 30秒 |
| 2 | 撒干料 | 均匀撒入，手抓拌至每块肉裹匀 | 1分钟 |
| 3 | 加辅料 | 蒜末+姜末+洋葱丝，抓匀 | 30秒 |
| 4 | 湿料混合 | 生抽+蚝油+老抽+料酒+清水，搅匀 | — |
| 5 | **水分次打入** | 分2-3次倒入，每次吸收完再加，同方向搅打至发黏 | 3-5分钟 |
| 6 | 判断终点 | 手抓肉翻转不掉落、盆底无残留水 | — |
| 7 | 加蛋液+淀粉 | 同方向搅打1分钟 | 1分钟 |
| 8 | 封油 | 淋色拉油轻翻拌匀（**不搅打**） | 30秒 |
| 9 | 入冰箱 | 密封袋挤出空气或保鲜膜紧贴肉面，**0-4℃**冷藏 | 按部位 |

| ✅ 正确 | ❌ 错误 |
|--------|--------|
| 水2-3次打入，吸收完再加，同向搅 | 一次全倒→水肉分离 |
| 一个方向搅到底 | 来回乱搅→蛋白网被扯烂 |
| 封油轻翻不搅打 | 继续猛搅→油破水膜 |
| 冰箱0-4℃ | 室温放置→细菌超标 |

---

### 阶段四：穿串

| 步骤 | 操作 | 参数 |
|:---:|------|------|
| 1 | 签子处理 | 清水浸泡 ≥30分钟 |
| 2 | 穿法 | 竹签从肉块中心垂直穿入 |
| 3 | 肥瘦搭配 | 里脊/腿肉：**3瘦+2肥**交替 |
| 4 | 块数 | 4-5块/串，块间距**3mm** |
| 5 | 长度 | 肉段8-10cm，两端留空≥5cm |
| 6 | 码放 | 平铺不叠放，串间留空隙 |

| ✅ 正确 | ❌ 错误 |
|--------|--------|
| 签泡30分钟 | 干签直接烤→签断 |
| 瘦-肥-瘦-肥-瘦 | 全瘦→干柴 |
| 块间距3mm | 紧贴→接触面烤不透 |

---

### 阶段五：烤制

| 步骤 | 操作 | 参数 | 时间 |
|:---:|------|------|:--:|
| 1 | 引炭 | 果木炭燃至全部灰白、无明火、无黑烟 | — |
| 2 | 铺炭 | 厚5-8cm，距烤网**12-15cm** | — |
| 3 | 预热 | 烤网预热至微微冒烟(~200℃)，涂牛板油防粘 | — |
| 4 | 上串 | 平铺，串间距≥2cm | — |
| 5 | 刷油 | 料油薄刷两面 | — |
| 6 | 第一面 | 中大火烤至焦黄斑纹+冒清亮肉汁 | 60-90秒 |
| 7 | 翻面撒盐 | 翻第二面，薄撒盐 | 60-90秒 |
| 8 | 第三面 | 翻面，补刷油 | 60秒 |
| 9 | 第四面+撒料 | 翻面，低撒孜然/辣椒面 | 30-45秒 |
| 10 | 大火收尾 | 移至最旺火区，两面各烤 | 10-15秒×2 |
| 11 | 判断熟度 | 肉汁清澈+竹签插入无血水+表面焦黄 | — |
| 12 | 打签子 | 轻敲两端震落浮料 | — |
| 13 | 出餐 | 趁热上桌 | ≤2分钟 |

### 烤制核心参数

| 参数 | 数值 |
|------|:-----:|
| 总时间 | 4-6分钟 |
| 翻面次数 | 4次 |
| 炭面距烤网 | 12-15cm（两拳高） |
| 温度区间 | 200-280℃ |
| 中心最低熟温 | 71℃ |
| 上脑/肋条最佳熟度 | 七成熟 |
| 里脊/腿肉最佳熟度 | 全熟 |

| ✅ 正确 | ❌ 错误 |
|--------|--------|
| 炭烧到全部灰白再用 | 黑炭明火→煤烟味+瞬间焦 |
| 全程翻4次 | 一直翻→肉汁流干 |
| 炭距12-15cm | 贴炭→秒焦 / 太高→不熟 |
| 撒料第四面临出时低撒 | 烤前就撒→料烤糊发苦 |
| ≤2分钟上桌 | 烤好放凉再上→肉回缩变硬 |

## 八、通俗科学原理速记

| 口诀 | 原理 |
|------|------|
| **横着切、肉才嫩** | 逆纹切断纤维→一咬就散开 |
| **碱开门、水进去** | 小苏打碱性撑开蛋白质→水被锁进肉里 |
| **水三打、同向搅** | 分次打水+同方向→蛋白质织网兜住水 |
| **油封住、水不跑** | 油膜隔绝空气+锁水+导热均匀 |
| **冰箱腌、菌不长** | 0-4℃细菌不繁殖 |
| **少翻面、汁水留** | 一面烤定型再翻，汁水稳定在中心 |
| **糖是香、不是甜** | 糖=美拉德反应燃料→焦香味来源 |

| 肉串烤出来干柴 | 没封油/翻面太多/烤太久 | 检查封油步骤；控制翻面4次；缩短烤制时间 |
| 肉有碱味/苦味 | 小苏打超量 | 降至<3g/斤，增加糖量掩盖 |
| 腌完出水多 | 没打上劲/水一次倒入 | 严格分次打水，直到发黏手粘不掉 |
| 外面焦了里面生 | 炭太近/炭有明火 | 调整炭距12-15cm；等炭烧透灰白无明火 |
| 竹签烤断了 | 没泡水 | 必须泡≥30分钟 |
| 腌制时肉发酸 | 室温放置太久 | 立即丢弃！0-4℃冰箱腌制 |
| 客人说不够咸 | 嘉兴口味偏咸下酒 | 盐调至5-6g |
| 客人说孜然不够 | 偏好北方口味 | 孜然调至5g；备桌上孜然罐供客人自加 |
