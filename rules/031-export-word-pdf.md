# 031-导出Word/PDF

> 将用户审查通过的完整配方方案导出为标准文档格式（Word 或 PDF），方便打印、保存和店内培训使用。

---

## 目的

将 030 规则产出的完整配方方案，转换格式化为标准的美观文档，支持：
- 打印后张贴在厨房操作台
- 分享给员工用于培训
- 存档到配方库进行管理

---

## 触发器

**WHEN** 030-用户审查确认流程全部通过后。

---

## 输入

- 030 规则产出且用户已逐项确认的**完整配方方案**

---

## 行为

### 步骤1：确认导出格式

询问用户导出偏好：

```
请选择导出格式：
1. Word（.docx）——可用 Word/WPS 编辑，方便后续微调
2. PDF —— 不可编辑，格式固定，适合打印和分享

您更倾向于哪种格式？
```

### 步骤2：生成文档

#### Word 格式生成规范

```markdown
【文档结构】
1. 封面：菜品名称 + 口味风格 + 适用场景
2. 配方参数表：格式化的表格
3. 成本信息：成本总览
4. 操作流程：分阶段的有序步骤
5. 关键节点速查卡：一页纸的快速参考
6. 避坑清单：常见错误对照表
7. 添加剂说明（如有）：安全使用卡

【格式要求】
- 标题：黑体/加粗，层级分明
- 表格：有边框，表头有底色
- 用量数字：红色加粗（重点突出）
- 操作步骤：编号列表，关键步骤加粗
- 警告信息：黄色背景高亮（如安全上限）
- 页脚：生成日期 + "本配方经科学联网验证"
```

#### PDF 格式生成规范

同 Word 格式要求，额外：
- 确保所有字体嵌入
- 表格不跨页断裂
- 适合 A4 纸打印

### 步骤3：文档内容结构

```
【封面页】
═══════════════════
  {dish_name}
  专业配方操作方案

  口味：{region_category}风味
  场景：{scene}
  总重：{total}g | 耗时：{time}分钟
  生成日期：{date}
═══════════════════

【第1页】配方参数
{完整原料清单表格}

【第2页】成本信息
{成本核算表 + 平替说明}

【第3-5页】操作流程
{分阶段完整步骤 + 通俗原理 + 关键节点判断}

【第6页】速查卡
{一张纸的厨房快速参考：关键温度/时间/判断标准}

【第7页】避坑清单
{常见错误对照表}

【第8页】添加剂安全卡（如有）
{添加剂用量 + 使用方法 + 注意事项 + 安全上限}

【尾页】
═══════════════════
  本配方所有参数均经联网交叉验证
  科学验证置信度：{X}%

  食品添加剂推荐符合 GB 2760-2024
  最终使用责任在经营方

  生成工具：餐饮配方自动生成器 v{version}
═══════════════════
```

### 步骤4：交付确认

```
【导出完成】

文件已生成：
📄 {dish_name}_配方操作方案.docx（或 .pdf）
保存路径：{path}

您可以：
- 直接打印张贴在厨房操作台
- 分享给员工进行标准化培训
- 存档到您的配方管理库

如需修改任何内容，请告诉我。祝生意兴隆！🎉
```

---

## 规则约束

- **禁止**：在用户最终审查完成前导出
- **要求**：文档中必须标注科学验证置信度和添加剂安全说明
- **要求**：关键用量数据必须突出显示（便于厨房操作时快速定位）
- **要求**：必须包含速查卡（一页纸快速参考）方便厨房张贴
- **注意**：如涉及添加剂推荐，文档中必须有明确的安全警告

---

## 输出

- **配方方案文档**：`.docx` 或 `.pdf` 格式
- **交付确认**：文件路径 + 使用建议
