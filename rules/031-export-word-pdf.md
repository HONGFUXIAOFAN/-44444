# 031-导出Word/PDF

> 将用户审查通过的完整配方方案导出为标准文档格式（Word 或 PDF），方便打印、保存和店内培训使用。

---

## ⛔ 强制执行声明（优先级：P0）

> **本规则共17项强制要求（字体4项 + 配色2项 + 表格5项 + 内容3项 + 文件3项）。导出前必须逐项通过格式自检清单。任一项未通过 = 禁止交付。**

### 强制门禁规则

| # | 强制要求 | 违规即拒绝交付 |
|---|---------|:---:|
| 1 | **必须使用模板脚本** `templates/export_recipe_template.py` 的 `build_document()` 函数，禁止从零手写导出脚本 | 🔴 |
| 2 | **生成前**必须逐项对照"格式自检清单"（共17项），确认全部合规 | 🔴 |
| 3 | **生成后**必须运行 `self_check()` 函数，将自检结果展示给用户 | 🔴 |
| 4 | **生成脚本（调用方）用后即删**，仅保留 `.docx` 产出文件和模板 | 🔴 |
| 5 | 文件保存至 `~/Desktop/`，文件名格式 `{菜品名}_{客户信息}_配方方案.docx` | 🔴 |

### 最常违规项（高优先级警示）

> **以下5项是历史违规率最高的规范，导出时必须优先确认：**

| 排名 | 规范 | 正确值 | 常见错误 |
|:----:|------|--------|---------|
| 🔴1 | 正文字号 | **16pt** | 错用 9pt/10pt/10.5pt（把文档当论文排） |
| 🔴2 | 表格字号 | **14pt** | 错用 8pt/8.5pt/9pt（表格塞太满就缩字） |
| 🔴3 | 表头配色 | **#C62828 + 白字** | 错用蓝色/绿色/自定义色 |
| 🔴4 | 免责声明内容 | **固定4句话（逐字）** | 自己编7条免责条款 |
| 🔴5 | 禁用分页符 | **0 个** | 封面/章节间加 `add_page_break()` |

---

## 目的

将 030 规则产出的完整配方方案，转换格式化为标准的美观文档，支持：
- 打印后张贴在厨房操作台
- 分享给员工用于培训
- 存档到配方库进行管理

---

## 触发器

**WHEN** 030-用户审查确认流程全部通过后。

---

## 输入

- 030 规则产出且用户已逐项确认的**完整配方方案**

---

## 行为

### 步骤1：确认导出格式

默认导出 Word（.docx），保存至用户桌面。如用户无异议，跳过询问直接生成。

### 步骤2：生成文档

**⚠️ 必须使用模板脚本 `templates/export_recipe_template.py`**：
- 调用 `build_document(config)` 函数，填充配方内容数据（config dict）
- **禁止**从零手写导出脚本（如直接 `from docx import Document` 后逐段手写）
- 模板中所有格式常量（字体/配色/列宽/边距）已预置，不可在调用方覆盖

#### Word/PDF 格式生成规范（强制执行）

##### 字体与可读性（手机优先）

文档主要受众为中小B端餐饮用户，**大部分通过手机查看**，因此字体必须大：

| 文本类型 | 字号 |
|----------|:----:|
| 封面标题 | 28pt |
| 一级标题 | 24pt |
| 二级标题 | 20pt |
| 正文 | 16pt |
| 表格内文字 | 14pt（四号） |
| 表格内注释/速查卡 | 12-13pt |
| 行距 | 1.2（正文）/ 1.0（表格） |

##### 表格排版规则

**表格总宽（强制）**：
- 所有表格 `tblW` 必须设为 **20cm**（即 A4 页面满宽，适配 1.0-1.2cm 页边距）
- 各列宽度按下方列宽分配规则按比例缩放，确保列宽之和 = 20cm
- 禁止出现表格总宽 ≠ 20cm 的情况

**列宽智能分配（强制）**：

| 列内容类型 | 列宽 | 处理方式 |
|-----------|:----:|------|
| 序号/步骤编号 | 1.0-1.5cm | 窄列，居中对齐 |
| 净重/用量/时间/温度 | 1.5-2.5cm | 窄列，居中对齐 |
| 合规/判定标签 | 1.0-1.5cm | 窄列，居中对齐 |
| 原料名称/项目 | 3.0-5.0cm | 中等列宽 |
| 处理方式/说明/做法 | 剩余宽度（≥7cm） | 宽列，左对齐 |
| 关键参数/判断标准/要点 | 剩余宽度（≥7cm） | 宽列，左对齐 |

**表格紧凑规则（强制）**：
- 单元格内边距：上下 20dxa，左右 40dxa
- 表格内行距：1.0
- 表后段落间距：Pt(1-2)
- 表头字体加粗，数据行不加粗

**表格配色方案（强制）**：
- 表头：暗红底 `#C62828` + 白色字
- 数据行：白底与浅粉 `#FFF0F0` 交替
- 正文色：深灰 `#333333`
- 强调色：暗红 `#C62828`
- 速查卡底色：`#FFF5F0`

##### 段落间距规则

- 段后间距：Pt(2-4)
- 段前间距：Pt(0)
- 标题前间距：Pt(6-10)
- 标题后间距：Pt(2-4)
- 分隔线使用 `━` 替代空白行，减少空间浪费

##### 分页规则

- **禁止使用任何分页符**（`add_page_break`）
- 内容自然流排，A4 页边距设为 1.0-1.2cm 以最大化可用宽度
- PDF 导出时自动分页，由打印机驱动自然处理

##### 内容规范

- **绝对禁止**在文档正文、页眉页脚、封面、尾页中出现任何"AI生成""自动生成""人工智能"等字样
- 文档不设尾页声明（原有的"生成工具：餐饮配方自动生成器"尾页删除）
- 文档中不标注"生成日期""生成工具"等元数据
- 封面仅保留：菜名、客户信息、核心参数（出餐速度/保存期）

##### 文档结构

```
1. 封面：菜品名称 + 客户信息 + 核心参数
2. ⚠️ 重要提示/免责声明（独立醒目段落，浅黄底色 #FFFDE7 + 深灰粗体 16pt，内容见下方"免责声明规范"）
3. 配方参数表（泡椒底料酱 / 高汤 / 南瓜泥 / 单份出餐）
4. 标准化操作流程（5阶段28步骤 + 每阶段正误对比）
5. 保存方法详解（底料酱 / 高汤 / 南瓜泥）
6. 通俗原理（7条）
7. 添加剂安全清单（GB 2760合规）
8. 地域适配建议
9. 厨房速查卡（建议单独打印张贴）
```

##### 免责声明规范（强制）

**位置**：封面之后，配方参数表之前，为文档第一处正文内容。

**样式**：
- 底色：浅黄 `#FFFDE7`
- 字体：深灰 `#333333` 粗体 16pt
- 段落内边距：上下 80dxa，左右 120dxa
- 标题：`⚠️ 重要提示（请务必阅读）`，暗红 `#C62828` 18pt 粗体

**固定内容**（逐字输出，不可改动）：
```
本方案基于科学配方理论基础，具体实际操作需要根据本地口味再做调整。
建议先做小锅测试验证，确认口味满意后再批量生产。
本方案仅为参考建议，不代表最终味道方案，请结合实际情况灵活调整。
配方不是万能的，实际操作经验同样重要。
```

##### 交付规则

- 文件保存路径：用户桌面（`~/Desktop/`）
- 文件名格式：`{菜品名}_{客户信息}_配方方案.docx`
- 生成脚本用后即删，仅保留 `.docx` 产出文件

### 步骤3：文档内容结构

按以下顺序生成（无分页符，自然流排）：

```
1. 封面：菜品名称 + 客户信息 + 核心参数（出餐速度/保存期）
2. ⚠️ 重要提示/免责声明（独立醒目段落，浅黄底色 #FFFDE7 + 深灰粗体 16pt，固定内容不可改动）
3. 配方参数表（泡椒底料酱 / 高汤 / 南瓜泥 / 单份出餐标准）
4. 标准化操作流程（5阶段28步骤 + 每阶段正误对比 ✅❌）
5. 保存方法详解（底料酱 / 高汤 / 南瓜泥 + 保质原理）
6. 通俗原理（7条，厨房人说人话）
7. 添加剂安全清单（GB 2760 合规 + 用量/国标对照）
8. 地域适配建议（自助小料 + 操作说明）
9. 厨房速查卡（浅粉底色大框，建议单独打印张贴）
```

## 规则约束

- **禁止**：在用户最终审查完成前导出
- **禁止**：文档中出现任何"AI生成""自动生成""人工智能""生成工具""生成日期"等字样
- **禁止**：在文档中使用分页符
- **要求**：字体适配手机阅读（正文16pt、表格14pt四号、标题20-28pt）
- **要求**：表格配色统一为暗红表头(`#C62828`白字) + 白底/浅粉(`#FFF0F0`)交替
- **要求**：表格总宽必须为 20cm（A4 满宽），禁止出现非 20cm 宽度的表格
- **要求**：表格列宽智能分配——序号/用量等标注列窄(1.0-2.5cm)，处理方式/说明/做法/关键参数等内容列宽(≥7cm)，各列之和 = 20cm
- **要求**：必须包含免责/重要提示声明，放在封面之后、配方参数表之前，样式为浅黄底色(`#FFFDE7`)深灰粗体16pt，内容固定不可改动
- **要求**：表格紧凑（单元格边距上下20dxa/左右40dxa，行距1.0）
- **要求**：必须包含速查卡（一页纸快速参考）方便厨房张贴
- **要求**：文件保存至用户桌面（`~/Desktop/`）
- **要求**：生成脚本用后即删，仅保留文档产出文件
- **注意**：如涉及添加剂推荐，文档中必须有明确的安全警告
