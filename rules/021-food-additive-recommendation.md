# 021-添加剂合理推荐

> 在 GB 2760-2024 食品安全国家标准范围内，推荐可适量使用、能显著提升菜品风味的食品添加剂/复合调味料，附带精确用量、使用方法、安全上限和注意事项。

---

## 目的

帮助中小B端餐饮用户在合法合规的前提下，用食品添加剂/复合调味料提升菜品风味竞争力。同时通过完整的安全说明防止误用、滥用。

---

## 触发器

**WHEN** 012-标准化操作流程生成获得用户确认后（与 013 并行执行）。

---

## 输入

- 012 规则产出的**标准化操作流程**
- 010 规则产出的**配方参数表**（原料信息）

---

## 行为

### 步骤0：先判断是否需要添加剂

```markdown
【添加剂判断原则】
1. 传统工艺（现熬骨汤/香料卤制）能达到理想风味 → 优先不推荐添加剂
2. 工业化/连锁化生产需要风味稳定 → 可推荐合规添加剂
3. 规模化降本需求 → 推荐复合调味料替代方案

优先级：传统工艺 > 复合调味料 > 单一食品添加剂
```

> - 膏状产品必须在 **50℃以下** 加入，高温会破坏香气成分

> - 使用后应**适量减少盐、味精**等其他调味料

### 步骤3：按"五维增味体系"生成推荐

```
核心逻辑："鲜味打底 → 厚度支撑 → 香味提魂 → 圆润调和 → 酸度平衡"

【层1-鲜味打底】味精 + I+G（经典组合，I+G放大鲜味3~8倍）
【层2-厚度支撑】酵母提取物 / 肉膏骨膏（提供醇厚底味）
【层3-香味提魂】乙基麦芽酚 / 复合香精膏（去腥增香、嗅觉味觉联动）
【层4-圆润调和】琥珀酸二钠 / 甘氨酸 / L-丙氨酸（做清透感或甜润感）
【层5-酸度平衡】柠檬酸 / 苹果酸（防止鲜腻发闷）
```

按菜品类型给出黄金配比：

#### 肉类卤制/红烧

```
味精 : I+G : 酵母提取物 : 乙基麦芽酚 : 甘氨酸
 8   :  1  :    5     :   0.3    :  0.5      （相对比例）

建议总量：每kg原料添加 10~15g 增味体系
乙基麦芽酚不超过 0.2g/kg（超量发苦）

可选升级方案：
+ 猪肉/牛肉膏 2~4g/kg（增强肉感底味）
+ 红曲红/辣椒红 适量（上色）
+ 复合磷酸盐 1~3g/kg（如需保水嫩化）
+ D-异抗坏血酸钠 0.2~0.5g/kg（护色抗氧化）
```

#### 汤羹/火锅底料

```
味精 : I+G : 酵母提取物 : 琥珀酸二钠 : 乙基麦芽酚
 6   :  1  :    4     :    3     :   0.1

建议总量：每kg汤底添加 8~12g

可选升级方案：
+ 骨膏/骨髓浸膏 2~5g/kg（增加汤底厚度）
+ 鸡肉膏 2~4g/kg（鸡汤底专用）
+ 黄原胶 0.5~1g/kg（增加汤底挂壁感）
+ 火锅飘香剂 0.1%~0.3%（火锅/麻辣烫专用）
```

#### 素食/豆制品

```
味精 : I+G : 酵母提取物 : L-丙氨酸 : 琥珀酸二钠
 5   :  1  :    6     :    3    :    2

建议总量：每kg原料添加 6~10g
乙基麦芽酚 ≤ 0.1g（素汤可不加）
```

#### 酱料/调味品

```
味精 : I+G : 酵母提取物 : 甘氨酸
 10  :  1  :    3     :  2

建议总量：每kg添加 15~20g

可选升级方案：
+ HVP/HAP 2~8g/kg（增加肉感）
+ 变性淀粉 10~30g/kg（酱料浓稠感）
+ 黄原胶 0.5~3g/kg（替代淀粉，口感更好）
```

#### 腌制肉类/串串

```
复合磷酸盐 : D-异抗坏血酸钠 : 味精 : I+G
    2~3    :     0.3~0.5   :  5   : 0.5     （g/kg原料）

可选升级方案：
+ 木瓜蛋白酶 / 菠萝蛋白酶（天然嫩肉）按需
+ 香辛料精油 0.1~0.5g/kg
+ 乙基麦芽酚 0.1~0.15g/kg（去腥增香）
```

## 规则约束

### 安全红线（绝对禁止）
- **禁止**：推荐 GB 2760 范围外的添加剂
- **禁止**：推荐用量超过 GB 2760 最大使用量
- **禁止**：为禁用人群（如婴幼儿食品）推荐添加剂
- **禁止**：推荐工业级（非食品级）添加剂
- **禁止**：推荐已被 GB 2760-2024 新禁用的添加剂（如脱氢乙酸钠用于面包/糕点）
- **禁止**：推荐未经精确称量的亚硝酸钠（小餐饮无称量条件时禁止推荐）

### 质量要求
- **要求**：每种添加剂必须附带完整安全说明（用量上限 + 使用方法 + 禁忌）
- **要求**：必须联网查询最新版 GB 2760-2024 确认合规性
- **要求**：用量以"克/公斤原料"和"本配方具体用量"两种方式标注
- **要求**：区分"食品添加剂"和"天然调味料"（酵母提取物、HVP/HAP、肉膏骨膏等属于天然调味料或复合调味料，不受GB 2760限量限制）
- **要求**：遵循"五维增味体系"逻辑推荐——先传统后添加剂，先天然后合成
- **注意**：用户可能对添加剂有顾虑，不强制推荐，所有推荐均为可选
- **注意**：如同时推荐多种添加剂，必须说明协同效应和总量控制

### 配方修正对照表（强制要求）

**当对客户的现有配方做任何增减时，必须生成"配方修正对照表"**，格式如下：

```markdown
## 配方修正对照表（原配方 → 修正配方）

### 香料类

| # | 原料 | 原用量 | 修正用量 | 变化 | 原配方问题 | 修正原因 |
|----|------|--------|---------|------|-----------|---------|
| 1 | 小茴香 | 1000g | 1200g | +200g(+20%) | 占香料24%，被花椒麻椒压制，主角地位不突出 | 提升至40%占比，成为君料核心，增香去膻主力 |

### 增味体系（新增）

| # | 添加剂 | 原用量 | 修正用量 | 变化 | 新增原因 |
|----|--------|--------|---------|------|---------|
| 1 | 酵母提取物 | 0 | 100g | 🆕新增 | 原仅靠味精提鲜，鲜味单一乏味；酵母提取物提供天然醇厚底味，去腥增肉感 |

### 未变动项

| # | 原料 | 用量 | 未调整原因 |
|----|------|------|-----------|
| 1 | 牛羊肉 | 75kg | 主料分量不变 |
```

**对照表规则**：
- **必须三类齐全**：香料类（增减项）+ 增味体系（新增项）+ 未变动项（说明为什么不动）
- **每一项修改必须回答**：原配方有什么问题？为什么做出这个修改？
- **"原配方问题"栏**：用一句话说清原配方中该原料的问题（如"用量偏高X倍导致腻口""占比被压制主角不突出"）
- **涉及GB 2760添加剂的修改**：必须标注法规依据
- **新增项**：标注 🆕，说明填补了什么空缺
