# 030-用户审查确认流程

> 定义配方生成完成后，用户对完整方案进行最终审查确认的标准流程，确保交付前无遗漏、无错误。

---

## 目的

在所有规则执行完毕后（含022实用有效性验证），向用户呈现完整的配方方案，提供系统化的审查检查清单，确保用户逐项确认后才能导出交付。

---

## 触发器

**WHEN** 022-实用有效性验证 通过并获得用户确认后。

---

## 输入

- 所有前置规则的最终产出物（配方参数、操作流程、成本核算、添加剂推荐等）
- **022-实用有效性验证报告**（4维度评分 + 风险项 + 未覆盖问题）

---

## 行为

### 步骤1：组装完整配方方案

将所有前置规则的产出物汇总为一份完整方案：

```markdown
# 【{dish_name}】完整配方操作方案

## ⚠️ 重要提示（请务必阅读）
> 本方案基于科学配方理论基础，具体实际操作需要根据本地口味再做调整。
> 建议先做小锅测试验证，确认口味满意后再批量生产。
> 本方案仅为参考建议，不代表最终味道方案，请结合实际情况灵活调整。
> 配方不是万能的，实际操作经验同样重要。

---

## 📋 基本信息
- 菜品名称：{dish_name}
- 目标地区：{region}（{region_category}口味）
- 出餐场景：{scene}
- 配方总重：{total}g
- 预估单份成本：{cost}元
- 总耗时：{time}分钟
- 难度等级：{level}

---

## 🥘 配方参数
{010-配方参数表}

## 🔬 科学验证结果
{011-验证结论摘要}

## 💰 成本核算
{020-成本总览 + 平替选择摘要}

## 👨‍🍳 标准化操作流程
{012-完整操作流程 + 014-通俗原理}

## 🌍 地域适配说明
{013-调整了的调料 + 调整理由}

## 🧪 添加剂使用说明
{021-添加剂推荐（如有）}

## ⚠️ 避坑清单
{012-常见错误表}

## 🎯 实用有效性验证
{022-验证报告摘要：4维度评分 + 风险项}
```

### 步骤2：引导用户逐项审查

按以下顺序逐项确认：

```markdown
【最终审查——请逐项确认】

### 审查1：配方完整性 ✅/❌
- [ ] 原料清单是否齐全？有无遗漏？
- [ ] 每种原料的用量是否合理？
- [ ] 配方总重是否符合您的出餐规格？
> 如有问题请指出，我将回退到对应步骤修改。

### 审查2：科学性可信度 ✅/❌
- [ ] 配方参数是否经过了联网验证？
- [ ] 验证置信度是否可接受？
- [ ] 有无您存疑的配方参数需要进一步核实？
> 科学验证置信度：{X}%

### 审查3：操作可行性 ✅/❌
- [ ] 操作步骤是否清晰可执行？
- [ ] 每个关键节点的判断标准您是否理解？
- [ ] 时间/温度是否符合您厨房的实际情况？
- [ ] 常见错误您是否已知晓并会注意？

### 审查4：实用有效性（022验证结论复核） ✅/❌
- [ ] 场景匹配度：方案是否真的为您的场景（{scene}）量身定制？
- [ ] 操作真实可行性：在您的厨房条件下（设备/人手/空间）是否真的能做出来？
- [ ] 商业有效性：成本结构是否支持您的目标定价？能否真的赚钱？
- [ ] 问题解决度：方案是否直接解决了您最初的核心诉求？
- [ ] 风险项是否已知晓并接受？
- [ ] 未覆盖问题是否需要回退补充？
> 022验证结论：场景匹配度{评分} | 操作可行性{评分} | 商业有效性{评分} | 问题解决度{评分}

### 审查5：成本合理性 ✅/❌
- [ ] 配方总成本是否在您的预算内？
- [ ] 高价原料的平替方案是否已确认（采用/不采用）？
- [ ] 单份成本是否符合您的定价策略？

### 审查6：地域适配 ✅/❌
- [ ] 调整后的口味方向是否符合当地客人偏好？
- [ ] 是否需要进一步微调某些调料用量？

### 审查7：添加剂安全性 ✅/❌
- [ ] 推荐的添加剂您是否理解其作用和用法？
- [ ] 安全上限和注意事项您是否已知晓？
- [ ] 您是否决定采用？（每项单独确认）

### 审查8：整体评价 ✅/❌
- [ ] 这个配方方案您是否满意？
- [ ] 是否可以直接使用了？
- [ ] 有没有任何需要修改的地方？
```

### 步骤3：处理审查结果

| 审查结果 | 处理方式 |
|---------|---------|
| 全部通过 | 进入 031-导出 Word/PDF |
| 某项不通过 | 明确问题→回退到对应规则→修改→只重新执行受影响的下游规则 |
| 多项不通过 | 逐项列出→按依赖顺序逐一回退修改 |

### 步骤4：审查通过确认

```
🎉 全部审查通过！

您的【{dish_name}】配方方案已完成，准备导出。

下一步：031-导出为 Word/PDF 格式。

是否现在导出？
```

---

## 规则约束

- **禁止**：跳过任何审查项直接导出
- **禁止**：用户未明确确认时默认通过
- **要求**：每项审查必须用户明确回复确认
- **要求**：不通过项必须记录修改需求和回退路径
- **注意**：回退修改后必须重新审查受影响项（含022重新验证）

---

## 输出

- **完整配方方案**：所有规则产出物的汇总版本
- **审查记录**：8 项审查的逐项确认结果
