# 014-科学原理通俗化注入

> 为配方操作流程中的关键步骤注入通俗易懂的食品科学原理说明，让用户不仅知道"怎么做"，还知道"为什么这么做"。

---

## 目的

将食品科学原理（美拉德反应、蛋白质变性、乳化作用、酶解反应等）用通俗语言解释，：
1. 提升用户对配方合理性的信任感
2. 帮助用户在操作失误时能自行判断问题出在哪里
3. 让零基础用户也能理解背后的科学逻辑

---

## 触发器

**WHEN** 013-地域口味适配完成并用户确认后。

---

## 输入

- 012 规则产出的**标准化操作流程**
- 013 规则调整后的**配方参数**

---

## 行为

### 步骤1：识别需要通俗化的关键步骤

扫描操作流程，标记符合以下条件的步骤：
- 涉及化学/物理变化（如上色、乳化、凝固、发酵）
- 涉及温度敏感操作（如焯水、油炸、炖煮）
- 涉及顺序依赖（如先A后B不能反）
- 用户容易犯错的环节

### 步骤2：为每个关键步骤注入通俗原理

```markdown
## 【科学原理通俗化】

### 🔬 关键步骤1：{步骤名称}（如"炒糖色"）

**通俗说法**：
糖在高温下（180-200℃）会慢慢融化、变色，先变成黄色，再到枣红色——这时候就是最佳时机，肉一下锅，糖色就牢牢裹在肉上，烧出来红亮亮的，特别有食欲。但温度再高颜色变深褐色，糖就焦了，做出来的肉发苦。

**科学原理**：
这是糖的焦糖化反应（Caramelization）。蔗糖在 160℃ 开始融化，180-200℃ 发生脱水、聚合反应，生成焦糖色和焦糖风味物质。超过 200℃ 则碳化产生苦味物质。

**做对/做错的后果**：
- ✅ 枣红色冒小泡时下肉 → 色泽红亮、微甜不腻、肉香浓郁
- ❌ 深褐色浓烟时下肉 → 表面发黑、有明显焦苦味、一盘菜报废

---

### 🔬 关键步骤2：{步骤名称}（如"焯水"）

**通俗说法**：
焯水一定要冷水下锅！为什么呢？热水的话，肉一进去表面瞬间就凝固了，里面血水被"锁"住了出不来，再怎么煮都有一股腥味。冷水下锅慢慢升温，血水、杂质才有时间跑出来，捞掉浮沫之后肉就干净了。

**科学原理**：
肌肉蛋白质在 60-70℃ 开始变性凝固。热水下锅 → 表面蛋白瞬间凝固形成致密层 → 内部毛细血管中的血液和肌红蛋白无法渗出 → 成品腥味重、汤色浑浊。冷水下锅 → 缓慢升温 → 血液和可溶性蛋白有充足时间溶出 → 撇去浮沫后肉干净、汤清澈。

**做对/做错的后果**：
- ✅ 冷水下锅，水开焯 3 分钟 → 肉无腥味、口感干净
- ❌ 开水下锅焯水 → 外面的肉发柴、里面的血水出不来、一股腥味

---
{继续其他关键步骤...}
```

### 步骤3：整合到操作流程中

将通俗原理说明嵌入到操作流程的对应步骤中，而非单独成章：

```
【原来】
步骤3.2：炒糖色，温度 180-200℃，至枣红色。

【注入后】
步骤3.2：炒糖色（🔥 关键）
  - 操作：锅中放油 20ml + 冰糖 40g，小火加热至 180-200℃
  - 判断标准：糖融化 → 变黄 → 变枣红色 + 冒小泡 = 最佳时机
  - 🔬 为什么：焦糖化反应。糖在高温下变色产生焦香风味。枣红色=刚好，深褐色=焦苦失败。
  - ❌ 常见错误：火太大了→糖没化开直接焦了，一锅黑苦。
```

### 步骤4：通俗易懂度自检

每一条通俗解释必须通过三问：
1. 初中文化水平的人能否听懂？
2. 是否用了具体的生活类比而非抽象概念？
3. 是否说清了"做对的好处"和"做错的后果"？

### 步骤5：等待用户确认

```
【通俗化注入完成】

已为 {N} 个关键步骤注入科学原理通俗解释：

{列出被注入的步骤}

请您确认：
1. 通俗解释是否足够通俗易懂？（有不理解的地方请告诉我）
2. 是否有其他步骤您也想了解背后的原理？
3. 原理说明部分是否需要更详细或更简略？

```

## 2026-10-26补充：原理说明必须服务于A/B决策

- 对A、B两版分别解释关键差异为什么可能改善顾客提出的痛点。
- 说明香料释放、挥发性香气、油脂载香、鲜味/厚度及热藏影响时，应区分已有研究支持的机制与对当前配方的推断。
- 不得把原配方比例或总重说成科学上必须保持的常数；配方数字由优化设计决定，再做准确计算。
- 不得声称某版本已在门店实测更好，除非确有相应记录。

## 规则约束

- **禁止**：直接输出学术论文式的科学定义
- **禁止**：在一个步骤中堆积过多原理（每步最多 2-3 句原理说明）
- **要求**：每个原理说明必须配"做对/做错"对比
- **要求**：必须使用生活类比（如"像煮鸡蛋一样"、"跟和面一个道理"）
- **注意**：原理说明不能取代操作说明，是增强而非替代

### 格式自检清单（输出前逐项检查）

- [ ] 每个关键步骤包含：通俗说法 + 科学原理 + 做对/做错后果
- [ ] 通俗说法通过"初中文化能听懂"测试
- [ ] 每个步骤最多 2-3 句原理说明（不堆积）
- [ ] 原理说明嵌入操作流程中，非单独成章
